# Competitor analysis

SpendSense is a **free audit → share URL → optional email → Credex CTA** funnel, not a full spend management platform.

## Alternatives users might use today

| Alternative | What it does | Gap vs SpendSense |
|-------------|--------------|-------------------|
| **Spreadsheet + invoices** | Manual seat counts | No benchmarks, slow |
| **Vendr / Zylo / Torii** | Full SaaS procurement | Overkill for 5–20 person teams; not AI-tool-specific |
| **ChatGPT “audit my stack”** | Ad-hoc advice | Invents savings; no sourced list prices |
| **Vendor dashboards** | Per-tool usage | No cross-tool overlap (Cursor + Copilot) |
| **Credex (direct)** | Credit buyback | Needs lead qualification — this tool is top-of-funnel |

## Positioning

**Mint for AI tool spend** — fast, free, honest when there is nothing to fix.

Differentiators:

1. Deterministic savings math with [`PRICING_DATA.md`](../PRICING_DATA.md) sources
2. Zero-savings honest path ([`PRODUCT_DECISIONS.md`](PRODUCT_DECISIONS.md))
3. Shareable audit URL for internal Slack debates
4. Credex handoff only above $500/mo savings

## Why not build more?

Assignment scope is lead-gen proof, not competing with procurement suites. Depth is in **rules + trust**, not feature parity.
